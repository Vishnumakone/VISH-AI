# Vishnu AI MVP
This is a first responsive prototype for desktop/mobile.

Features:
- Demo chat (not connected to a real AI model)
- Plan vs Actual MIS calculator
- Email draft helper
- Trading sample-data analysis only
- Interview answer template
- Local browser settings
- Basic PWA manifest/service worker

No AI provider, Groww API, broker, login, or cloud sync is connected. No real orders are placed. Do not put API keys or sensitive details in the browser code.

Open index.html to test. For Android install features, publish via HTTPS. For actual AI replies later, connect a server-side backend and store keys in server environment variables.
